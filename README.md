
# JavaCloudDrive — Java 多客户端网盘系统

## 一、项目简介

基于 Java 实现 C/S 架构的网盘系统，支持一个服务端同时为多个客户端提供服务，实现用户注册登录、文件上传、文件管理、分享提取、文件下载及在线浏览等功能。

## 二、人员分工

| 成员 | 负责模块 | 开发分支 |
| --- | --- | --- |
| A（组长） | 用户管理、公共架构 | feature/user |
| B | 文件上传 | feature/upload |
| C | 文件管理 | feature/manage |
| D | 分享与提取 | feature/share |
| E | 文件下载 | feature/download |

每位成员负责对应模块的客户端、服务端、数据库操作及功能测试。

## 三、开发计划

## 六、开发要求

1. 所有成员在各自的功能分支开发。
2. 公共字段和接口不得擅自修改。
3. 所有模块使用统一服务端和数据库。
4. 优先完成必做功能，再实现选做功能。
5. 由组长统一审核、合并及发布代码。
